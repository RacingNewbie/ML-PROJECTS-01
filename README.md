# Breast Cancer Classification 🎗️

This project focuses on **classifying breast cancer** as **malignant or benign** using machine learning models. Early detection of breast cancer is critical for effective treatment, and machine learning can assist healthcare professionals in making accurate and timely decisions.

---

## 🚀 Project Overview

Breast cancer is one of the most common cancers worldwide. Accurate and early diagnosis can significantly improve patient outcomes. This project uses supervised machine learning techniques to analyze medical data and classify tumors as malignant or benign based on their features.

---

## 💡 Features

- Predict whether a tumor is **malignant or benign**  
- Analyze tumor features like radius, texture, perimeter, area, smoothness, compactness, and more  
- Implement multiple classification models for comparison:
  - Logistic Regression  
  - Decision Tree Classifier  
  - Random Forest Classifier  
  - Support Vector Classifier (SVC)  
  - K-Nearest Neighbors (KNN)  
- Evaluate models using metrics such as **accuracy, precision, recall, F1-score**, and **confusion matrix**  

---

## 🧰 Technologies & Tools

- **Programming Language:** Python  
- **Libraries:** pandas, NumPy, scikit-learn, matplotlib, seaborn  
- **Machine Learning Models:** Logistic Regression, Decision Tree, Random Forest, SVC, KNN  
- **Data Visualization:** matplotlib, seaborn  

---

## 📊 Dataset

The dataset contains features computed from digitized images of fine needle aspirate (FNA) of breast masses. Some of the key features include:

- Radius, Texture, Perimeter, Area  
- Smoothness, Compactness, Concavity, Concave points  
- Symmetry, Fractal Dimension  

**Target Variable:** Tumor Class (Malignant / Benign)
